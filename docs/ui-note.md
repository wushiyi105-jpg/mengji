# UI 说明：梦记

- **谁在什么时刻打开**：给想观察作息的人。
- **首屏任务句**：昨晚，睡了多久。
- **主操作**：按「先记醒来的时间 → 补一句感受 → 一周一起回看」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：午夜和黎明之间的日志；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：午夜和黎明之间的日志。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给想观察作息的人：醒来先记时间和主观感受，梦境可单独设为私密；一周后把作息、质量和事件放在同一条时间带。
